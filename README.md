# Shiver Quiver

A armylist builder for the miniatures game Planet Shark, by Moonless games.

# No AI was used to make this piece of software.

We can't speak on behalf of the libraries we've chosen to use, but the development team has made a concious choice of not using AI to make this armylist builder.

LLMs was used as teaching tools of new technologies.

## Tech

 - React
 - Tailwind CSS
 - Supabase
 - React Router
 - JSON data
